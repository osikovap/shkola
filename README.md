# shkola

Це навчальний проєкт з HTML і веб-розробки.

У папці `hw-01` знаходяться три сторінки:
- `index.html` — головна сторінка
- `about.html` — сторінка "Про мене"
- `contacts.html` — сторінка "Контакти"

Мета проєкту — практикувати базову структуру HTML, навігацію між сторінками та створення простого вмісту для сайту.
